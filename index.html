About

One person.
Four disciplines.

I'm Roy — a marketing web developer. It's a deliberately hybrid title, and it covers four things most teams hire four people for. Over the last decade I've used all four to build and rebrand the marketing sites of Elementor, Wix, and now Lusha.

  1. 01

    Design

    Figma variables, design tokens and UX/UI calls. I think in components before I write a line of CSS, so what gets designed is what can actually ship.

  2. 02

    Code

    HTML, PHP, SCSS and JavaScript written by hand — no page builders. Reusable UI that survives contact with a real team and a real release schedule.

  3. 03

    Marketing

    Pages built to convert, then measured — Google Tag Manager, A/B tests, and the SEO groundwork. I ship for teams that count everything.

  4. 04

    Automation

    Claude Code skills and CI/CD pipelines that take a page from keyword to production in minutes, and convert a Figma page into editable WordPress.
